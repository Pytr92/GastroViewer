The currently available Census 2021 grid dataset contains provisional data submitted by the National Statistical Institutes by the Deadline 31.12.2022. 
The dataset must be labelled as ‘provisional’ and ‘under validation’.

File Naming Convention for  Files
<ORGANISATION>_<Parameter>_<Year>_<Version>.<format>
ESTAT_OBS-VALUE-T_2011_V1-0.tif – the total population data that European NSIs provided using national data sources as COG - GeoTIFF file (Raster - Format).
ESTAT_Census_2011_V1-0.gpkg – the total population data that European NSIs provided using national data sources as Geopackage (Vector - Format).
